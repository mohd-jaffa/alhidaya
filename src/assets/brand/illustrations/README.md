Generated with the built-in image-generation tool from the user’s approved pale-blue outline reference. No remote asset dependency or new client script.

The user’s latest instruction allows only exact source tool artwork or its omission. The initial approximate tool outlines were removed; only the care scene remains. It is lazy-loaded, hidden from assistive technology and pointer-transparent. This generated care scene is not claimed to be a pixel-identical extraction of the flattened reference.
